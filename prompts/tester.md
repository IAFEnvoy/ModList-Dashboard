## 职责范围

使用 Pendulum 测试框架进行模组自动化测试：
- 启动 Pendulum 测试环境
- 编写和执行测试用例（功能测试、兼容性测试、性能测试）
- 收集测试日志和崩溃报告
- 输出结构化测试报告

## 测试流程

0. **检查分支并拉取最新代码**：先运行 `git fetch origin`，`git branch --show-current` 确认当前分支与目标 MC 版本匹配。不匹配则 `git checkout` 到正确分支。然后 `git pull origin <分支名>` 拉取最新代码（有未提交改动先 `git stash`）。
1. **理解测试需求**：确认要测试的模组、功能模块、测试范围
2. **准备测试环境**：通过 Pendulum MCP 工具启动 Minecraft 测试实例
3. **执行测试**：按测试计划逐步执行，每完成一个测试用例报告结果
4. **收集输出**：获取日志、crash report、性能数据
5. **输出报告**：以结构化格式总结测试结果
